Share to bookdrop from an iPhone

Safari on iOS cannot install a site into the share sheet, so a Shortcut does it: it sends the shared file to bookdrop and opens its confirmation page. Build it once in the Shortcuts app.

  1. In Shortcuts, tap + and name the new shortcut bookdrop.
  2. Tap ⓘ, turn on Show in Share Sheet, and set the share sheet types to Files only. A Receive Files from Share Sheet block appears at the top.
  3. Add Get Contents of URL. Set the URL to {{ base }}/drop, then expand it:
    • Method: POST
    • Headers: add Accept with the value application/json
    • Request Body: Form; add a field of type File, key file, value Shortcut Input
  4. Add Get Dictionary Value: get the Value for key url in Contents of URL.
  5. Add If: Dictionary Value has any value.
  6. Inside the If, add Open URLs with Dictionary Value. The value is the confirmation page's whole address; open it as it is.
  7. Under Otherwise, add Get Dictionary Value for key error in Contents of URL, then Show Alert with it, so a refused file says why.

To use it, download the store's .acsm or EPUB in Safari, then in Safari's downloads or in Files, tap Share and choose bookdrop. The phone must reach {{ base }}, on the home network or the tailnet, as it does for this page.
